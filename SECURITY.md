# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in **Git & Conquer**, please report it privately rather than opening a public issue:

- Use **GitHub Private Vulnerability Reporting** under the repository's **Security → Advisories** tab, or contact the maintainers at Vylor AI.
- Please include steps to reproduce and the potential impact of the issue.

We will acknowledge receipt and work with you to resolve the issue promptly.
